## Install

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
</Tabs>

```ts
import { PGlite } from '@electric-sql/pglite'
import { rdkit } from 'pglite-rdkit'

const pg = await PGlite.create({ extensions: { rdkit } })
await pg.exec('CREATE EXTENSION rdkit')

const { rows } = await pg.query(`SELECT mol_to_smiles('C1=CC=CC=C1O'::mol) AS smiles`)
// [{ smiles: 'Oc1ccccc1' }]
```

In Vite, exclude both packages from dependency pre-bundling in `vite.config.ts`. They find their
WebAssembly files through `import.meta.url`, which pre-bundling breaks:

```ts
import { defineConfig } from 'vite'

export default defineConfig({
  optimizeDeps: { exclude: ['@electric-sql/pglite', 'pglite-rdkit'] },
})
```

:::caution[Supported PGlite versions]
Only `@electric-sql/pglite` 0.5.x (`>=0.5.0 <0.6.0`, PostgreSQL 18) is supported. Every 0.5.x
release is tested in CI.
:::

Invalid SMILES raises a normal Postgres error, and the database stays usable. For every function
and operator, see the [RDKit cartridge documentation](https://www.rdkit.org/docs/Cartridge.html).

## Differences from Server RDKit

The WebAssembly build leaves out three RDKit components:

- **Avalon**: `avalon_fp` raises an error
- **Coordgen**: 2D coordinates use RDKit's default depiction
- **FreeType**: text in SVG drawings is drawn as paths

The README explains
[how the extension is built](https://github.com/asiomchen/pglite-rdkit#how-it-works) and
[which PGlite and runtime versions are supported](https://github.com/asiomchen/pglite-rdkit#supported-versions).
