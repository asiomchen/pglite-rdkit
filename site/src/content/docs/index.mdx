## Install

<Tabs syncKey="pkg">
  <TabItem label="npm">
    ```bash
    npm install @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
  <TabItem label="pnpm">
    ```bash
    pnpm add @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
  <TabItem label="yarn">
    ```bash
    yarn add @electric-sql/pglite pglite-rdkit
    ```
  </TabItem>
</Tabs>

```ts
import { PGlite } from '@electric-sql/pglite'
import { rdkit } from 'pglite-rdkit'

const pg = await PGlite.create({ extensions: { rdkit } })
await pg.exec('CREATE EXTENSION rdkit')

const { rows } = await pg.query(`SELECT mol_to_smiles('C1=CC=CC=C1O'::mol) AS smiles`)
// [{ smiles: 'Oc1ccccc1' }]
```

In Vite, exclude both packages from `optimizeDeps`, because they find their WebAssembly files
through `import.meta.url`.

:::caution[Supported PGlite versions]
Only `@electric-sql/pglite` 0.5.x (`>=0.5.0 <0.6.0`, PostgreSQL 18) is supported. Every 0.5.x
release is tested in CI.
:::

Invalid SMILES raises a normal Postgres error, and the database stays usable. The
[RDKit cartridge documentation](https://www.rdkit.org/docs/Cartridge.html) lists every function.
Two features aren't in the WebAssembly build: Avalon fingerprints, and FreeType text (labels in
SVG are drawn as paths). There's more in the
[README](https://github.com/asiomchen/pglite-rdkit#readme).
