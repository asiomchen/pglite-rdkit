## What the numbers mean

- **Indexed similarity searches stay fast.** With a GiST index on Morgan fingerprints, the 10
  most similar molecules come back in under a millisecond at every size tested, and a Tanimoto
  threshold search takes about 10 ms at 100,000 molecules.
- **Building the database is the slow part.** Parsing SMILES, computing fingerprints and building
  the indexes takes over a minute at 100,000 molecules, more than half of it in the GiST index on the
  molecules. Build it once: keep it in IndexedDB (`idb://`), where reopening takes about a
  second, or ship a prebuilt database with PGlite's `dumpDataDir()` and `loadDataDir`.
- **A tab needs about 1.1 GB before any data**, for PGlite and the WebAssembly runtime, and about
  1.5 GB (in memory) to 1.8 GB (IndexedDB) at 100,000 molecules. In Node, file storage (a
  directory as `dataDir`) keeps memory nearly flat.
- **One core.** PGlite runs PostgreSQL in a single thread, so a long query blocks the database.
  Run it in a [Web Worker](https://pglite.dev/docs/multi-tab-worker) to keep the page responsive.
- **Compared with a server,** RDKit in WebAssembly is about 1.5 times slower on queries and 2 to 3
  times slower on parsing and index builds than native PostgreSQL on one core. A server also
  needs far less memory, and can use more cores.

## How it was measured

Each size runs in a fresh browser (Playwright Chromium, a production build) or a fresh Node
process, with the molecules taken in a fixed shuffled order from the
[MolPILE](https://huggingface.co/datasets/scikit-fingerprints/MolPILE) dataset. Every size runs
three times, each from scratch. As in seaborn's `lineplot`, the charts show the mean of the three
and a band for its 95% confidence interval (1,000 bootstrap resamples); the tables give the
interval in brackets. Within a run, each query is timed three times and its median kept. Memory is the peak resident memory of
the browser tab's process or the Node process, sampled from outside.

The server baseline runs the same steps against native PostgreSQL with the RDKit cartridge from
[cheminfo_db_images](https://github.com/asiomchen/cheminfo_db_images), in a Docker container
limited to one CPU core and configured like PGlite (`fsync` off, no parallel workers, the same
memory settings). Its timings include a local network round trip, and on macOS Docker runs in a
Linux VM.

The benchmark is in the repository's
[`bench/` folder](https://github.com/asiomchen/pglite-rdkit/tree/main/bench), with instructions
to rerun it on another machine or a later release.

## Data

The molecules come from MolPILE, a collection of about 222 million standardized molecules from
PubChem, UniChem, Mcule, ChemSpace, SuperNatural3 and COCONUT. The benchmark uses its 1M subset
and downloads it at run time.

> for molecular representation learning. arXiv:2509.18353 (2025).
